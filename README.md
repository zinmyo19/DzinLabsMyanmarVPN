# DzinLabs Myanmar VPN

VPN client for family in Myanmar — built for reliable Facebook / Messenger calls.
Created by Dominic.

Based on v2rayNG (2.2.6) with a Myanmar red & gold theme.

## Protocols

VLESS + REALITY (recommended for Myanmar), Trojan, Hysteria2, Shadowsocks, VMess.

## Download

Get the latest APK from [Releases](../../releases). Install directly — no build tools needed.
Coexists with the official v2rayNG app (separate package `com.dzinlabs.myvpn`).

## Server setup

This app is a client — it needs a server profile to connect.
See [Myanmar-VPN-server-setup.md](Myanmar-VPN-server-setup.md) for how to set up
your own Xray VLESS + REALITY server (Singapore VPS recommended), or import a
`vless://` link / QR code from your provider via the ⨁ button in the app.

## Notes

- Android 8.0+
- No censorship bypass is ever guaranteed — results vary by ISP, routing and current blocking rules.
